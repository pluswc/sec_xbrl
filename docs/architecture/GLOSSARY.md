# 재무 조회와 데이터 가용성 용어

공시의 실제 재무기간, 공시 공개와 우리 시스템의 사용 가능 시점을 구분한다.
정의는 합의된 의미이며 미결정 운영 정책은 [인터뷰 기록](../implementation/company-latest-availability-20261107.md)에 둔다.

## 용어

**조회기준시점**: 어떤 시점까지 알려지고 사용 가능했던 자료를 조회할지 정하는 기준이다. 실제 배치 조회는 뉴욕 날짜와 그날까지 확인된 준비 완료 시각을 사용한다.
_Avoid_: 오늘 최신, 공시일과 같은 시점

**재무선택기준일**: 발행물의 `financial_as_of`처럼 재무자료 선택에 적용한 공개정보 cutoff다. 그날 우리 시스템에서 이미 사용 가능했다는 증거는 아니다.
_Avoid_: 시스템 준비일, 수집 완료일

**공시일시**: SEC에 공시가 공개된 시점이다. 날짜만 확인된 자료는 날짜 정밀도로 보존하며 임의의 시각을 붙이지 않는다.
_Avoid_: 데이터 수집일, 분석 준비일

**수집완료시각**: 특정 원본 버전을 우리 시스템이 실제로 수집 완료한 시각이다. 공개된 공시일시와 다를 수 있다.
_Avoid_: 공시일, 파일 수정시각

**분석준비완료시각**: 불변 분석 버전이 검증된 산출물로 처음 조회 가능해진 시각이다. 이후 rebuild 시각으로 바꾸지 않으며 개별 지표의 AVAILABLE 여부와 구분한다.
_Avoid_: 마지막 rebuild 시각, 값이 존재하는 시각

**실제재무기간**: 회사가 보고한 실제 시작·종료일 또는 잔액 기준일이다. 회사 FY/Q와 calendar bucket은 이 기간을 표현하는 좌표이며 공시 제출 순서가 아니다.
_Avoid_: 공시일, 모든 회사에 공통인 FY 날짜

**사용지연(lag)**: 투자에 사용할 자료의 반영 시점을 조절하는 설정이다. 미국 거래일 단위이며 기본값 0은 준비 완료 후 즉시 사용할 수 있음을 뜻한다. 양수는 준비일 이후 판단일까지의 거래 세션을 센다.
_Avoid_: 무조건 다음날, 자동 일별 배치 실행

**실제가용이력**: 특정 불변 버전의 공개·수집·최초 분석 준비를 실제 기록으로 입증하는 이력이다. 누락된 시각을 공시일이나 mtime으로 채운 것은 여기에 속하지 않는다.
_Avoid_: 공시일만으로 증명한 과거 사용 가능성

**가정기반가용정보**: 실제 준비 이력이 부족할 때 공시일과 가정한 lag 등의 규칙으로 구성하는 가용성 정보다. 실제 준비 시각이 확인되지 않은 경우 실제가용이력과 별도로 표시한다.
_Avoid_: 실제가용이력, 관측된 최초 준비시각
