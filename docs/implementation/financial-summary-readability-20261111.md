# 재무 요약의 정렬과 숫자 읽기

2026-11-11 사용자는 하단 성장성·수익성·현금흐름·안정성 지표의 폭과
개별 상자 밀도를 정리하고, 금액은 소수 0자리, 백분율은 소수 1자리로
표시하도록 승인했다. 기준은 `b1b783d418`이다.

하단 지표는 전체 폭 범주 밴드 안에서 공통 이름·값·단위 열을 사용한다.
1200px 이상에서는 같은 폭의 두 열, 좁은 화면에서는 한 열로 표시한다.
위쪽 주요 지표 8개는 위치와 항목을 유지하면서 여백과 구분선 중심으로
표시한다. 누락·품질 설명과 전년 대비 부호 상태는 바로 읽을 수 있다.
정확한 공표값, 관측 ID와 공식은 기존 툴팁 및 접을 수 있는 근거 표에 있다.

금액 단위는 기존 백만 USD이며 소수 0자리로 반올림한다. 백분율은 소수
1자리, 배수는 기존 소수 2자리다. 화면 반올림은 정확한 십진 문자열로
처리한다. 0이 아닌 값이 0으로 반올림되는 경우 `<1`, `>-1` 또는
`<0.1`, `>-0.1`처럼 범위를 표시하고 정확한 툴팁을 유지한다.
차트도 같은 정밀도로 표시하며 같은 눈금 이름은 한 번만 표기한다.
축 범위와 점·막대 위치, 준비된 원값과 계산 정책은 그대로 사용한다.

기업·재무기간·출처, 전체 지표와 기존 항목 추가·삭제·순서 변경, 비교,
저장·재열기·내보내기 기능을 검증한다. 처음 승인된 변경은 표시 컴패니언과 관련 표시 검사 및 문서다.

## 추가 승인: 선택 지표의 준비된 비교와 작은 차트 쌍

같은 날 사용자는 선택 가능한 모든 MONEY 지표의 전년비와 PERCENT 지표의
전년 대비 %p 변화를 승인했다. `financial_comparison_v2.py`는 검증된 부모의
카탈로그를 읽고 board-only v2 결과를 만든다. 기존 v1 생산기 함수와 9개
시계열의 각 결과 필드는 유지한다. 기존 v1 브리지도 계속 읽을 수 있다.
카탈로그와 스크리닝 조건은 수정하지 않는다.

MONEY에는 기존 양수·음수·0 정책을 재사용한다. 추가 항목의 부호 전환은
양수/음수 전환으로 표현하며 영업손익으로 단정하지 않는다. PERCENT는
정확한 십진 `현재−전년`의 PERCENTAGE_POINT로 발행하고 비율의 성장률을
계산하지 않는다. RATIO는 명시적인 비교 정의가 없으면 수준만 표시한다.
동일 회사·정의와 버전·단위와 배율·차원·기준·as-of·품질 및 재귀 입력의
매핑·분모 의미를 검사한다. 분모가 0 이하이거나(TTM은 공표된 분모 정책에 따라 네 분기의 합이 0 이하) 준비된 입력 계보가
불충분하면 비교를 발행하지 않는다. 예컨대 별도 원천 증거만 있는 계산 부채는
`SUPPORTED_LINEAGE_NOT_PREPARED`를 남긴다.

연간/분기는 직전 FY/같은 회계분기의 전년을 사용한다. INSTANT는 같은
회계기간의 실제 종료일을 비교하며 흐름 기간이나 TTM 합으로 취급하지 않는다.
흐름은 기존 정상 기간을 검사하고 TTM은 각 4개의 연속·고유 입력을 유지한다.
정의/버전/분모/기간 또는 재귀 입력이 불명확하면 원값은 유지하고 이유를 표시한다.
UI는 발행된 비교를 현재 관측 ID·값·실제 기간과 맞춘 후 표시하고 계산하지 않는다.
금액 차트 위, 전년비/%p 막대 아래 순서를 지키며 상단의 반복 기간 눈금과
상자 배경을 줄인다. 두 차트의 공유 기간 선택·스크롤·정확한 근거 표는 유지한다.

- `ruff check .`: 통과. 관련 브리지·소비자·표시 wrapper 검사와 실제 자료
  발행·브라우저 및 독립 검증은 별도 증거로 후속 기록한다.

원본·부모 카탈로그/발행물·매출 구성·기록을 수정하지 않는다. 기존 source
compatibility를 재작성하거나 완화하지 않는다. 새 helper는 그 검증된 reader를
받는 별도 오프라인 producer 코드다. 기존 v1 builder는 그대로 호출할 수 있으며
`prepare_financial_growth.publish`는 v2 builder를 사용한다. 재현은 기존 고정
manifest/compatibility 인자와 새 destination으로 같은 CLI를 실행한다.
