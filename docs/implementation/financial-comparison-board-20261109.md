나란히 읽고 항목을 추가·삭제·재정렬하는 표시 개선을 승인했다. 기준 커밋은

API, 브리지, 분석 발행물, 저장 저널은 기존 경로를 사용한다.

## 재무 요약

- 현재 보기에 있는 매출, 영업이익, 영업활동 현금흐름, 표준화 FCF가 기본이다.
  체크리스트에서 최대 8개 지표를 선택하고 위로·아래로·삭제 버튼을 사용한다.
  선택은 해당 기업 상세의 화면 상태다.
- 넓은 화면에서는 두 열, 좁은 화면에서는 한 열이다. 좁은 화면에서는 차트 안에서
  가로로 이동해 눈금 크기를 유지하고 보드 내 차트들의 가로 위치를 맞춘다. 각 카드의 수준과 전년비
  축은 별도다. 기간 선택 또는 차트 포인터로 모든 카드에서 같은 기간을 짚는다.
  상세 기간표에서 공표값, 단위, 실제 재무기간 및 누락 이유를 확인한다.
- 연간 매출의 `revenue_yoy`와 분기 매출의 `quarter_revenue_yoy`만 각 매출
  정의에 명시적으로 연결한다. 카탈로그에서 정의와 단위가 맞을 때 사용한다.
  TTM, 나머지 금액 지표와 비율에는 현재 발행된 대응 전년비가 없음을 표시한다.
  시계열 관측값으로 새 성장률을 계산하지 않는다.
- 연간은 기업 프로필의 준비값을 사용한다. 분기·TTM은 선택한 지표와 발행된
  전년비에 한해 기존 분기 시계열 API·응답 검증·캐시를 재사용한다.
  순서 변경은 새 요청을 만들지 않는다. 기업 상세·조회 기준이 바뀌거나 상세가
  닫힌 뒤 지연 응답으로 화면을 갱신하지 않는다. 기존 개별 지표 추이와 기간표는
  접을 수 있는 영역에서 계속 사용한다.

## 매출 구성과 흐름

- [공시 표시 계층과 기존 표](investor-analysis-interface.md#2026-11-09-제품서비스-공시의-표시-계층)는
  선택 기간의 소계, 하위 항목, 중복 제거, 별도 공시 분류, 제외 범위와 출처를
  유지한다. 표 아래 전폭 추이 보드에서 같은 보기의 여러 항목을 선택한다. 연결 매출은
  선택 가능한 별도 기준 시리즈다. 준비된 금액과 전년비만 점으로 표시하며,
  매핑 구간 근거가 없으므로 선을 연결하지 않는다.
- 금액 축을 공유하는 추이를 먼저 표시하고, 같은 항목의 공시 전년비를 별도
  축 아래에 표시한다. 비중 보기를 켜면 발행된 비중과 분모를 표시한다.
  동일 항목의 색과 선 패턴을 패널에서 유지하며, 기간 선택과 차트 포인터는
  공통 기간을 강조한다. 전체 기간값 표에서 정확한 공표값과 기간을 확인한다.
- 시리즈는 공시 축·멤버 및 부문 범위를 보존한다. 금액·전년비·비중은 준비된
  값만 표시한다. 값 0은 관측점이다. 누락, 매핑 구간 변경, 매핑 검토 필요
  구간에서 선이 끊기고, 비중은 분모의 범위가 달라져도 선이 끊긴다.
  각 비중에 연결 매출 또는 해당 부문 소계를 적는다. 항목들은 서로 겹칠 수
  있으므로 합계를 산출하지 않는다. 전년비 비교값은 같은 공시에서 가져오며
  추이의 전년 금액과 다를 수 있다.

## 확인 명령

```sh
node --test tests/screening/*.test.cjs
python -m pytest -q tests/test_screening_display_assets.py tests/screening/test_screening_explorer.py tests/screening/test_revenue_breakdowns.py
```

실제 브라우저 확인에는 준비된 연간·분기·TTM 발행물과 제품·서비스 계층을
포함한 매출 구성 파일이 필요하다. 넓은 화면과 모바일에서 보드 편집, 연동 기간,
금액·전년비·비중, 누락 표시를 확인하고 기존 표와 저장 내역을 대조한다.
