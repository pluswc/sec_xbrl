## 독립 검토의 표시 수명주기 수정

첫 후보 `aed017ed59`의 고정 설명이 resize/늦은 응답의 DOM 교체 뒤 사라지는
문제를 수정했다. 고정 항목·기간·표시 모드를 DOM 참조와 분리해 보관하고,
두 보드의 명시적 beforeRender/afterRender에서 현재 scope를 확인한 뒤 새
설명과 원천/값으로 복원한다. 활성 범례·차트·설명 닫기 버튼도 같은 항목/모드로
포커스를 복원한다. 회사·기준·그룹/선택 변경으로 유효하지 않으면 고정을 해제한다.
hover 자체는 SVG를 다시 그리지 않는다.

점/터치 고정은 자기 차트에 preventScroll 포커스를 주므로 첫 Escape는 설명만
해제한다. 범례는 native 포커스를 유지한다. 설명을 닫을 때 숨은 닫기 버튼에
포커스를 남기지 않는다. 모든 매출 모드와 재무 성장 비교 설명은 기존 공표 행과
참조의 actualPeriod를 함께 표시하며 새 날짜나 계산을 만들지 않는다.

수정 후 전체 Node 89개와 Ruff가 통과했다. 새 DOM 교체 검사는 고정 설명의
