# 데스크톱 재무 워크벤치의 근접 비교

2026-11-11 사용자 승인. 기준 `f46460086e`의 준비된 비교·헤더 정렬·지역별
매출 범위와 모든 자료/기록 기능을 유지하며 표시 자산만 조정한다.
interface-design과 기존 ledger ivory/filing paper/ink/slate/annotation blue 체계를 사용한다.

- 매출 표는 항목 280–360px, 금액 120–140px, 비율 100–120px와 짧은 원천
  열을 갖는 내용 중심 폭으로 표시한다. 하단 지표도 이름과 값의 거리를 제한하고
  넓은 화면에서 여러 범주 열로 배치한다. 좁은 화면은 표/차트 내부 스크롤이다.
- 재무 비교 카드는 컨테이너 폭에 따라 1/2/3/4열(약 360px 최소)로 배치한다.
  SVG 좌표를 실제 카드 폭으로 준비하고 글자 크기를 줄이지 않는다. 금액 위,
  작은 전년비/%p 아래, 공유 기간·누락·음수 상태·원값 근거를 유지한다.
- 핵심 4개와 카탈로그의 성장성·수익성·현금흐름·안정성·기타 그룹 및 사용자
  선택 그룹을 제공한다. 그룹별 선택과 순서를 별도로 기억하고 기존 추가/삭제/
  순서 변경/최대 8개를 유지한다. 카탈로그 category만 사용하며 새 회계 분류를 만들지 않는다.
- 매출 선택/컨트롤을 위에 모으고 범례를 각 차트 바로 위에 둔다. 비중값이
  하나도 없으면 큰 빈 그림 대신 사유를 표시한다. 비중 합계나 새 계산을 만들지 않는다.
- hover/focus/tap은 이름·실제 기간·값·단위와 누락 사유를 가까이 표시하고,
  관련 차트·범례를 연결 강조한다. 매출 비중에는 분모, 전년비에는 같은 공시의
  비교값 원칙을 표시한다. 같은 기간의 모든 선택 항목 readout과 정확한 근거 표를 유지한다.
  클릭/키보드로 고정하고 Escape로 해제한다. 회사·기준 변경의 과거 상태를 표시하지 않는다.

허용 변경은 app.js/app.css, 관련 Node 표시 검사와 문서다. backend, producer,
artifact, 원본·카탈로그·계산·저널·내보내기 정책은 변경하지 않는다. native
controls와 escaped labels를 사용하며 외부 의존성을 추가하지 않는다.

수락은 전체 Node/Ruff와 2560·1920·1464·1024·390px 실제 자료에서 근접 폭,
카드 수·높이, 그룹 기억·순서 경계, hover/키보드/고정 해제·누락·근거,
기존 매출 계층/지역 범위·보드·저장기록의 유지다.

선택·순서 편집은 기존 picker details 안에 함께 두고, 그룹 선택은 기간/형태/
축과 한 줄에 둔다. 설명은 차트를 밀지 않는 가까운 absolute 패널이다.
고정 전에는 포인터 이벤트를 가로채지 않고, 고정 후 닫기·스크롤·원천 링크를
사용할 수 있다. 첫 Escape는 활성 설명만 해제하고 다음 Escape는 기존 기업
상세 닫기 동작에 전달한다. 폭 관측은 보드당 단일 ResizeObserver가 담당한다.
