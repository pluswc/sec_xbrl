# Nasdaq100 후보의 CIK·공시 지원 확인과 확장

2026-11-11 사용자는 Nasdaq 공식 후보 목록의 CIK와 지원 공시를 확인한 뒤
기존 수집과 검증 결과를 재사용하여 실제 대상을 확대하도록 승인했다.
현재 목록은 관찰일이 2026-11-11인 102개 증권이다. 구성 효력일은
미확인이다. 같은 CIK의 복수 주식은 회사 하나로 처리하며 증권 목록은
별도로 보존한다. 기존 50개 중 겹치는 대상은 27 CIK, 28개 증권이다.

SEC submissions의 CIK·ticker와 공시 목록이 일치하는 미국 10-K·10-Q 및
그 수정 공시만 이번 준비 경로로 진행한다. 20-F·6-K, CIK 불명확 대상,
기존 승인에서 보류한 PEP 원본 오류는 사유와 함께 남긴다. 확인된 대상은
입력 5개 완료 회계연도와 후속 분기, 표시 4개 회계연도와 8개 완료
분기를 사용한다. 최근 상장으로 기간이 부족하면 기존 수집기의 실제
공시 기간 fallback과 부족한 범위를 그대로 기록한다.

첫 확장 발행의 공시 기준일은 기존과 같은 2026-10-25다. Nasdaq 구성
관찰일 2026-11-11과 재무 자료의 기준일을 구분한다. 기준일까지 공시된
자료만 사용하고 배치 가용 시각은 성공한 준비를 실제 확인한 시각이다.
기존 50개 회사와 지원되는 신규 회사의 합집합을 제공하며, 기존 발행과
저장 ID도 보존한다. 기존 50개의 재무 발행·Raw·History와 완료 검증을
재사용한다. 기준일 이후 새 공시는 이번 확장 발행에 포함하지 않는다.

## 실행 계약

`collection_operations.prepare_universe`는 고정된 SEC submissions를
오프라인으로 읽는다. 수집과 History 빌드는 선택한 회사 하나씩 실행하고
연간·분기 분석도 기존 생산기를 호출한다. 새 운영 도구는 작업별 입력과
완료 매니페스트 해시, 시각, 실행 시간·RSS·가용 디스크를 남긴다.
재개 시 성공한 결과의 해시를 먼저 확인한다. 수집 도구가 공시마다
기록하는 결과를 유지하고, 실패한 공시와 부족한 공시는 READY로 표시하지
않는다.

초기에는 신규 미국 회사 3개의 수집·빌드·연간·분기 준비를 순차 측정한다.
이후 같은 한도에서 지원 대상의 다음 회사를 진행한다. 작업당 시간 한도는
1시간, 프로세스 트리 RSS 중단 한도는
16GiB, 최소 가용 RAM은 4GiB, 최소 가용 디스크는 16GiB다. 동시에 무거운 회사 작업은 하나다.
기존 상세 전체 감사는 반복하지 않는다.

이번 실행에서 새로 생긴 압축 해제 폴더는 해당 공시의 Raw 스냅샷이
수집기에서 검증·수락된 뒤에만 정리한다. 보존 ZIP과 Raw 스냅샷은
유지한다. 후보 발행·조회용 projection·별도 저널 검사는 준비 완료 뒤
별도 단계로 인수하며 운영 주소 전환 전에 독립 검증을 받는다.

상태는 실행 계약 승인 및 운영 도구 구현 준비다. CIK 확인 파일,
첫 3개사 실제 측정, 지원·보류 목록, 새 발행과 운영 인수는 확보한
근거에 맞춰 순서대로 추가한다.

## 초기 확인과 도구 계약

SEC 확인은 58.68초에 완료했다. 기존 50개에 신규 지원 65 CIK를 더하는
115개사 후보이며, 일부 신규 회사의 준비 범위는 제한적이다. 지원하지
않는 공시 7개 증권, 기존 원본 오류 보류 PEP와 CIK 확정 보류 WBD를
별도로 기록했다. 오프라인 계획은 65개 모두 PREPARED, 선택 공시
1,320건이었다. 이 상태는 Raw·분석 준비 완료를 뜻하지 않는다.
7개사는 실제 가용 기간만 사용한다. ABNB의 기존 수집 도구 실행은
22건 수락, 41.454초, 프로세스 트리 최고 RSS 2,830,736 KiB였다.

운영 도구 `tools/nasdaq100_ops.py run-stage`는 `--config`,
`--config-sha256`, `--ticker`, `--stage`를 받는다. 단계는 `collect`,
`history`, `annual`, `quarterly`다. 고정 설정은 SEC 확인 파일, 기존
수집 계획 매니페스트와 universe 설정의 핀, 회사별 재사용 intake 경로,
출력 루트 및 캐시 경로를 선언한다. 이미 수락된 Raw intake가 완전하면
수집을 다시 호출하지 않고 다음 단계로 이어간다. 무거운 단계와 재개
판단은 동일한 프로세스 잠금 안에서 수행한다. 연간 기준 공시가 없는
회사는 연간 미가용 사유를 남기며 분기 자료는 별도로 준비한다.

실행 자료는 `work/nasdaq100-expansion-20261111`에, 신규 수집과 결과는
`data/raw/nasdaq100_20261111` 및 `data/processed/nasdaq100_20261111`에
둔다. 원래 발행물을 바꾸지 않는 동일 기준일 코호트 결합과 핵심·근거
조회 발행은 초기 회사 측정 뒤 별도 소스 범위로 확정한다. 기존 115개사
전체를 한 프로세스에 적재하는 방식의 메모리 사용은 미측정이다.
