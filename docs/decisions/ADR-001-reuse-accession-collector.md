# ADR-001 — Reuse Existing Accession Collector

## Status
Superseded by ADR-003.

## Decision
The existing SEC accession discovery process remains a reference implementation.
This project no longer consumes it as its upstream discovery component.

## Rationale
- superseded because the current project expands by company (CIK), rather than
  by the prior project's daily-index collection range

## Consequences
- see ADR-003 for the current discovery boundary
